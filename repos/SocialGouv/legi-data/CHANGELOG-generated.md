## Changelog : legi-data (30 derniers jours, au 2026-08-01)

### Résumé
Ce changelog couvre les 30 derniers jours et met en évidence les mises à jour régulières des données législatives, ainsi qu'une correction concernant la version de npm pour assurer la stabilité du projet. Les données sont mises à jour quotidiennement, ce qui permet de maintenir l'application à jour avec les dernières informations de Legifrance.

### Évolutions fonctionnelles
- Mises à jour quotidiennes des données législatives : les données ont été mises à jour les 2026-08-01, 2026-07-31, 2026-07-30, 2026-07-29, 2026-07-25, 2026-07-24, 2026-07-11, 2026-07-08, 2026-07-02 et 2026-07-01.
- Correction de la version de npm : La version de npm a été bloquée sur la version 11 pour éviter des problèmes de compatibilité. [#292](https://github.com/SocialGouv/legi-data/issues/292)
