## Changelog : legi-data (30 derniers jours, au 16 juin 2026)

### Résumé
Ce changelog couvre les 30 derniers jours d'activité sur le projet legi-data. Les principales évolutions concernent des mises à jour régulières des données de la base LEGI extraites de l'API legifrance.gouv.fr. Ces mises à jour sont déployées quotidiennement et sont disponibles au format JSON ou via une API TypeScript.
