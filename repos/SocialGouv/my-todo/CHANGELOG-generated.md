## Changelog : my-todo (30 derniers jours, au 17 mars 2026)

### Résumé
Ce mois-ci, l'application my-todo a bénéficié d'améliorations significatives concernant l'automatisation de la planification et de l'exécution des tâches. Les workflows de planification ont été optimisés pour une meilleure compatibilité avec les outils et une meilleure présentation du format Markdown. De plus, l'intégration avec Claude a été renforcée avec l'ajout de workflows dédiés à la planification et à l'action.

### Évolutions fonctionnelles
- Amélioration du prompt de planification pour assurer un format Markdown correct.
- Autorisation de l'utilisation des commandes `gh` dans le workflow de planification.
- Ajout de la possibilité d'utiliser l'outil "Write" dans le workflow de planification.
- Automatisation de la chaîne de planification vers l'action ou la demande de clarification.

### Évolutions techniques
- Implémentation d'un workflow Claude Code Action via SpecMap.
- Implémentation d'un workflow Claude Code Plan via SpecMap.
- Utilisation de `prompt` au lieu de `direct_prompt` pour une meilleure flexibilité.

### Autres changements
- Aucun changement significatif à signaler.
