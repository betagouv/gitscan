## Changelog : graal (30 derniers jours, au 4 juin 2026)

### Résumé
Ce changelog présente les récentes améliorations apportées à Graal, le système de traitement automatisé des amendements législatifs. Les modifications concernent principalement la stabilité et la configuration de l'infrastructure, avec quelques corrections de bugs pour assurer un fonctionnement optimal.

### Évolutions fonctionnelles
Aucune évolution fonctionnelle majeure n'a été déployée durant cette période.

### Évolutions techniques
- Correction d'un bug concernant la configuration de la sonde de vivacité (livenessProbe) [#1234](https://github.com/SocialGouv/graal/issues/1234)
- Ajustements des ressources CPU et RAM allouées à l'application en pré-production pour optimiser les performances et la stabilité.
- Rétrogradation d'un paquet Python pour éviter des échecs de construction.
- Correction de la version de `rapidfuzz` pour assurer la compatibilité.
- Mise à jour de la version de l'image Docker Python vers la version 3.14.

### Autres changements
Aucun autre changement significatif n'a été effectué durant cette période.
