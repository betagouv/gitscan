## Changelog : fiches-travail-data (30 derniers jours, au 17 juillet 2026)

### Résumé
Ce changelog fait état de la publication régulière de nouvelles données pour les fiches de travail, ainsi que d'une correction concernant la version de npm utilisée pour le projet. Ces mises à jour permettent de maintenir les données à jour et d'assurer la stabilité de l'environnement de développement.

### Évolutions fonctionnelles
- Ajout d'une nouvelle fiche de travail sur le burn-out ([6afc8bb](https://github.com/SocialGouv/fiches-travail-data/commit/6afc8bb7969211435a494007174751237212424b)).
- Mise à jour régulière des données des fiches de travail (plusieurs versions entre le 18 juin et le 17 juillet 2026).

### Évolutions techniques
- Blocage de la version de npm à v11 pour assurer la cohérence de l'environnement de développement et éviter des problèmes de compatibilité ([#444](https://github.com/SocialGouv/fiches-travail-data/issues/444), [44db456](https://github.com/SocialGouv/fiches-travail-data/commit/44db4567a4b01da6b418d5a61753d029d48ff522)).

### Autres changements
- Publication de nouvelles versions de données (4.1236.0 à 4.1264.0) via le bot Social Groovy Bot. Ces versions incluent des mises à jour de données régulières.
