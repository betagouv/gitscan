## Changelog : agora-front (30 derniers jours, au 21 juin 2026)

### Résumé
Les dernières mises à jour d'agora-front se concentrent sur l'amélioration de l'interface utilisateur, notamment pour les réponses du gouvernement et les consultations. Des corrections ont également été apportées à la navigation (fil d'ariane) et à la configuration du projet pour résoudre des problèmes de syntaxe et de compilation.

### Évolutions fonctionnelles
- Amélioration de l'interface utilisateur pour les réponses du gouvernement.
- Nouvelle interface utilisateur pour les réponses.
- Correction du fil d'ariane pour les consultations [#244](https://github.com/agora-gouv/agora-front/pull/244).
- Mise à jour des consultations.
- Ajout d'un fichier DCV Sectigo pour la sécurité.

### Évolutions techniques
- Correction de la configuration Nuxt/TypeScript pour résoudre des erreurs de compilation et d'importation.
- Désactivation temporaire de `strictNullCheck` dans la configuration TypeScript pour faciliter la résolution de problèmes.
- Corrections syntaxiques diverses dans le code.
- Ajout d'un thème et amélioration de l'interface pour les projets.
