## Changelog : agora-metabase-scalingo (30 derniers jours, au 23 septembre 2026)

### Résumé
Les évolutions récentes ont porté sur le renforcement de la sécurité de l'accès à l'instance Metabase.

### Évolutions techniques
- Sécurisation de l'accès réseau via l'ajout d'une configuration NGINX permettant le filtrage par adresse IP sur l'instance.
