## Changelog : france-chaleur-urbaine-ifpen (30 derniers jours, au 15 juin 2026)

### Résumé
Ce changelog marque le début du développement du comparateur de modes de chauffage pour IFPEN. La première version initialise le projet avec une base solide utilisant React, TypeScript et la bibliothèque de composants Design System Fr. L'application est conçue pour consommer les données et les calculs du paquet `@betagouv/france-chaleur-urbaine-publicodes`.

### Évolutions fonctionnelles
- Initialisation du projet avec l'interface utilisateur de base.
- Intégration de la bibliothèque `@betagouv/france-chaleur-urbaine-publicodes` pour les calculs de comparaison des modes de chauffage.

### Évolutions techniques
- Mise en place de l'environnement de développement avec Vite, React et TypeScript.
- Utilisation du Design System Fr (@codegouvfr/react-dsfr) pour l'interface utilisateur.
- Configuration des tests avec Vitest et @testing-library/react.
- Initialisation du workflow CI/CD avec `ci.yml`.

### Autres changements
- Initialisation du dépôt avec un fichier `overview.json` décrivant le projet.
- Ajout de la licence AGPL-3.0.
