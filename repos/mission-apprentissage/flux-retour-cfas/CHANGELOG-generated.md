## Changelog : flux-retour-cfas (30 derniers jours, au 07 août 2026)

### Résumé
Les interventions de ce mois se sont concentrées sur la stabilisation de l'environnement de développement et l'amélioration de la fiabilité des processus de tests automatisés. Aucune nouvelle fonctionnalité n'a été ajoutée pour les utilisateurs finaux durant cette période.

### Évolutions techniques
- Mise à jour de l'image Docker utilisée pour Metabase [#4657](https://github.com/mission-apprentissage/flux-retour-cfas/pull/4657)
- Unification de la version de Node.js sur l'ensemble de l'application pour garantir la cohérence des environnements [#4648](https://github.com/mission-apprentissage/flux-retour-cfas/pull/4648)
- Augmentation des délais d'attente (timeouts) des tests Vitest pour réduire les échecs lors de l'intégration continue [#4651](https://github.com/mission-apprentissage/flux-retour-cfas/pull/4651)

### Autres changements
- Ajout d'une commande CLI pour l'injection de données de test (sipa nancy) [#4654](https://github.com/mission-apprentissage/flux-retour-cfas/pull/4654)
- Harmonisation de la version de Yarn pour le développement local [#4652](https://github.com/mission-apprentissage/flux-retour-cfas/pull/4652)
