## Changelog : proconnect-espace-partenaires (30 derniers jours, au 07/09/2026)

### Résumé
Les récentes évolutions se concentrent sur l'amélioration de l'ergonomie mobile, l'enrichissement de la documentation pour les partenaires et le renforcement de la fiabilité des tests automatisés.

### Évolutions fonctionnelles
- Correction de problèmes d'affichage sur les interfaces mobiles (responsive design) [#439](https://github.com/proconnect-gouv/proconnect-espace-partenaires/pull/439)
- Mise à jour liée à la gestion des identifiants de sous-utilisateur (sub uid) [#442](https://github.com/proconnect-gouv/proconnect-espace-partenaires/pull/442)

### Évolutions techniques
- Amélioration de la suite de tests de bout en bout (E2E) grâce à l'intégration d'un fournisseur ProConnect simulé (mock) [#453](https://github.com/proconnect-gouv/proconnect-espace-partenaires/pull/453)
- Standardisation des commandes de scripts de développement pour une meilleure cohérence de l'environnement [#434](https://github.com/proconnect-gouv/proconnect-espace-partenaires/pull/434)

### Autres changements
- Documentation : ajout d'une page explicative concernant l'erreur `invalid_client` [#443](https://github.com/proconnect-gouv/proconnect-espace-partenaires/pull/443)
- Documentation : ajout de précisions sur les restrictions d'accès aux services [#426](https://github.com/proconnect-gouv/proconnect-espace-partenaires/pull/426)
- Documentation : mise à jour de l'URL de test RIE [#445](https://github.com/proconnect-gouv/proconnect-espace-partenaires/pull/445)
