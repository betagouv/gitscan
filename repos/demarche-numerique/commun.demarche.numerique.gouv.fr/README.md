# commun.demarche.numerique.gouv.fr

Ce dépôt est l'espace commun des instances qui font vivre le service public *Démarche Numérique*. Il réunit les informations stables de l'écosystème — qui contribue quoi, comment nous joindre, ce qu'on construit ensemble — et un espace d'échange pour les questions, les idées et les décisions collectives. Il s'adresse autant aux instances déjà engagées qu'à celles qui envisagent de nous rejoindre.
