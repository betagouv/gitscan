## Changelog : mesads (30 derniers jours, au 8 juillet 2026)

### Résumé
Cette mise à jour apporte des améliorations à l'interface d'administration, notamment un filtre permettant de mieux gérer les demandes d'accès pour les gestionnaires. Des corrections de code ont également été effectuées pour supprimer des avertissements et la version de Python a été mise à jour vers la version 3.13.

### Évolutions fonctionnelles
- Ajout d'un filtre par préfecture sur les demandes d'accès gestionnaire dans l'interface d'administration. [#152](https://github.com/MTES-MCT/mesads/pull/152)

### Évolutions techniques
- Mise à jour de la version de Python vers 3.13. [#147](https://github.com/MTES-MCT/mesads/pull/147)
- Refactoring de code et correction d'avertissements. [#154](https://github.com/MTES-MCT/mesads/pull/154)

### Autres changements
- Mise à jour des dépendances.
