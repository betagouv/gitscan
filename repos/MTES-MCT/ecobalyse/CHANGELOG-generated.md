## Changelog : ecobalyse (30 derniers jours, au 5 mai 2026)

### Résumé
Ce mois-ci, l'équipe a continué d'enrichir la base de données avec de nouveaux ingrédients et matériaux, notamment pour l'Union Européenne et les produits biologiques. Des améliorations ont été apportées à l'interface utilisateur, notamment pour l'explorateur et l'édition d'éléments, afin d'améliorer la performance et l'expérience utilisateur. Des corrections de bugs et des optimisations techniques ont également été réalisées.

### Évolutions fonctionnelles
- Ajout de l'information "date de dernière connexion" pour les utilisateurs.
- Amélioration de la recherche dans l'explorateur avec une recherche "facettée" plus légère.
- Possibilité d'éditer les éléments directement dans une fenêtre modale dédiée.
- Ajout de l'ingrédient "Minibus quadricycle à assistance électrique" à la base de données.
- Ajout de la possibilité de localiser les transformations d'éléments.
- Ajout de la possibilité de contribuer des exemples depuis l'interface utilisateur.
- Ajout du pays "Europe et Maghreb" à la base de données.

### Évolutions techniques
- Mise à jour des dépendances Python et Node.js.
- Suppression de l'authentification par cookie.
- Refactoring du code pour améliorer la performance de l'explorateur.
- Suppression de données obsolètes (densité de bétail, matériaux obsolètes).
- Amélioration de la gestion des erreurs dans le backend de contribution.
- Optimisation de la gestion des impacts détaillés.

### Autres changements
- Nettoyage de code et renommage de certains éléments dans la base de données (viande de porc, catégories EoL).
- Ajout de packages CTCPA à la base de données alimentaire.
- Suppression des données de picking dans l'explorateur textile.
- Ajout d'origines "outre-mer".
- Ajout de transformations de cuisson.
- Mise à jour des métadonnées alimentaires génériques.
- Ajout de compléments laitiers.
- Correction de titres pour améliorer la lisibilité du modèle de rapport de bug.
- Alignement des alias EoL.
- Correction des catégories EoL.
- Mise à jour de la base de données "heat-europe".
- Modification des types de matériaux dans la base de données.
- Correction de l'affichage des impacts dans le comparateur d'objets/VELI.
- Correction de bugs liés à l'exportation de graphiques comparatifs.
