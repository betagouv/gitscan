## Changelog : dialog-integrations (30 derniers jours, au 16 avril 2026)

### Résumé
Ce mois-ci, le projet dialog-integrations a principalement été axé sur l'intégration des données de la Sarthe et la correction de problèmes liés à l'importation des données, notamment pour les régions de Brest et de l'Aveyron. Des améliorations de la documentation et du code ont également été apportées.

### Évolutions fonctionnelles
- Intégration des données des chantiers de la Sarthe : les données de cette région sont désormais disponibles et prêtes pour la production. [#5](https://github.com/MTES-MCT/dialog-integrations/pull/5)
- Correction de l'identifiant pour Brest : l'identifiant des données de Brest a été corrigé pour assurer une intégration correcte. [#3](https://github.com/MTES-MCT/dialog-integrations/pull/3)
- Corrections pour l'Aveyron : des corrections ont été apportées pour finaliser l'intégration des données de l'Aveyron.

### Évolutions techniques
- Mise à jour des dépendances `uv` : les dépendances `uv` ont été mises à jour pour assurer la compatibilité et la sécurité du projet.
- Amélioration de la documentation : la documentation (README) a été mise à jour.
- Nettoyage et formatage du code : des améliorations de formatage ont été appliquées pour améliorer la lisibilité du code.

### Autres changements
- Correction d'une ligne superflue dans le code.
- Tentative d'utilisation d'une URL explicite pour résoudre un problème d'importation.
