## Changelog : keycloak-client-webhook (30 derniers jours, au 22 juillet 2026)

### Résumé
Cette mise à jour permet aux administrateurs de configurer plus finement les événements Keycloak pour lesquels des notifications webhook sont envoyées, directement dans la configuration du client Keycloak. Cela offre une plus grande flexibilité et un contrôle précis sur les données transmises aux applications externes.

### Évolutions fonctionnelles
- Il est désormais possible de configurer les événements envoyés via webhook directement dans la configuration du client Keycloak. [#2](https://github.com/MTES-MCT/keycloak-client-webhook/issues/2)

### Évolutions techniques
- Aucune évolution technique majeure n'a été apportée durant cette période.

### Autres changements
- Mise à jour des dépendances Maven via Dependabot [#1](https://github.com/MTES-MCT/keycloak-client-webhook/pull/1).
