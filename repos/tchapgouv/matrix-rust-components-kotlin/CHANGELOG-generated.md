## Changelog : matrix-rust-components-kotlin (30 derniers jours, au 23 juin 2026)

### Résumé
Ce changelog fait état de mises à jour régulières du SDK Matrix Rust intégré à ce projet Kotlin. Les principales évolutions concernent la synchronisation avec les nouvelles versions du SDK Rust, ainsi que des corrections et ajustements pour assurer la compatibilité et la stabilité du build, notamment pour le module crypto. Une mise à jour de Gradle a également été effectuée.

### Évolutions fonctionnelles
Aucune évolution fonctionnelle visible pour l'utilisateur n'a été apportée durant cette période. Les changements se concentrent sur la maintenance et la synchronisation avec le SDK sous-jacent.

### Évolutions techniques
- **Mise à jour du SDK Matrix Rust :** Le SDK a été mis à jour à plusieurs reprises pour suivre les dernières versions de `matrix-rust-sdk` :
    - Version 26.06.3 ([552cad7](https://github.com/tchapgouv/matrix-rust-components-kotlin/commit/552cad7))
    - Version 26.05.26 ([a6b2938](https://github.com/tchapgouv/matrix-rust-components-kotlin/commit/a6b2938))
    - Version 26.05.20 ([206b870](https://github.com/tchapgouv/matrix-rust-components-kotlin/commit/206b870))
    - Version 26.05.13 ([ff3deb0](https://github.com/tchapgouv/matrix-rust-components-kotlin/commit/ff3deb0))
- **Mise à jour de Gradle :** Gradle a été mis à jour vers la version 9.2.1 ([d38b4a4](https://github.com/tchapgouv/matrix-rust-components-kotlin/commit/d38b4a4)).
- **Corrections de build :** Des corrections ont été apportées pour résoudre des problèmes de build, notamment pour le module crypto ([a1bdffa](https://github.com/tchapgouv/matrix-rust-components-kotlin/commit/a1bdffa), [1c3eea4](https://github.com/tchapgouv/matrix-rust-components-kotlin/commit/1c3eea4), [43319c1](https://github.com/tchapgouv/matrix-rust-components-kotlin/commit/43319c1)).
- **Correction du dépôt Tchap :** Des ajustements ont été effectués pour assurer la compatibilité avec le dépôt Tchap ([00a42ef](https://github.com/tchapgouv/matrix-rust-components-kotlin/commit/00a42ef), [253d5ee](https://github.com/tchapgouv/matrix-rust-components-kotlin/commit/253d5ee)).
