## Changelog : vodozemac (30 derniers jours, au 06/08/2026)

### Résumé
Les activités récentes se sont concentrées sur la maintenance technique, l'amélioration de la qualité du code et l'optimisation des processus d'intégration continue (CI).

### Évolutions techniques
- Renforcement de la qualité du code avec l'activation du lint Rust `unreachable_pub`.
- Amélioration de la CI en ajoutant le numéro de version dans les commentaires de l'action GitHub `install-action`.

### Autres changements
- Mise à jour de la documentation du changelog pour inclure les détails concernant le support de l'encryption HPKE ([#377](https://github.com/matrix-org/vodozemac/pull/377)).
