## Changelog : tchap-docker-integration (30 derniers jours, au 23 mars 2026)

### Résumé
Ce changelog décrit les récentes modifications apportées à l'intégration Docker de tchap. Les changements se concentrent sur la simplification de la configuration par défaut pour utiliser une stack complète avec Element et Synapse, et sur la mise à jour des imports de claims pour une meilleure gestion des identités.

### Évolutions fonctionnelles
- La configuration par défaut utilise désormais la stack `with_element_synapse`, permettant de démarrer rapidement une instance tchap avec Element Web et Synapse.
- Utilisation de `main_tchap` pour une configuration plus cohérente.

### Évolutions techniques
- Mise à jour des imports de claims pour améliorer la gestion des identités et des autorisations [#issue à ajouter si applicable].
