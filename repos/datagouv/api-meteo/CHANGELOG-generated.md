## Changelog : api-meteo (30 derniers jours, au 8 mai 2026)

### Résumé
Ce changelog présente les récentes améliorations apportées à l'API météo. Les modifications se concentrent sur la correction de bugs liés à la gestion des années dans les requêtes, assurant ainsi une plus grande précision des données retournées.

### Évolutions fonctionnelles
- Correction de l'inclusion de l'année maximale spécifiée dans la requête. [#4](https://github.com/datagouv/api-meteo/issues/4)
- Correction des noms de colonnes pour garantir la cohérence des données retournées. [#4](https://github.com/datagouv/api-meteo/issues/4)
