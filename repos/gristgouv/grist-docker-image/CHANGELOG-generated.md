## Changelog : grist-docker-image (30 derniers jours, au 25 août 2026)

### Résumé
Les récentes évolutions se concentrent sur l'épuration de l'interface utilisateur en supprimant les éléments promotionnels et l'amélioration de la cohérence visuelle. Le projet a également bénéficié d'une mise à jour de l'application Grist et d'une optimisation de la gestion du style CSS pour faciliter la maintenance.

### Évolutions fonctionnelles
- Épuration de l'interface : suppression des bannières promotionnelles concernant les éditions Enterprise et l'utilisation de MCP [#74](https://github.com/gristgouv/grist-docker-image/pull/74).
- Améliorations visuelles : ajustement du fond du logo ANCT et suppression du thème d'avertissement dans le pied de page de version [#74](https://github.com/gristgouv/grist-docker-image/pull/74).

### Évolutions techniques
- Mise à jour de l'application Grist intégrée à l'image [#73](https://github.com/gristgouv/grist-docker-image/pull/73).
- Refactorisation du CSS : factorisation des règles communes dans un fichier `common-custom.css` pour une meilleure gestion des styles [#75](https://github.com/gristgouv/grist-docker-image/pull/75).

### Autres changements
- Corrections mineures de style de code.
