# Synthèse d'activité : openmaraude (du 05/06 au 12/06)

## Résumé de l'activité
L'activité de la période s'est concentrée sur le développement du système de gestion des suspensions. L'introduction d'une interface visuelle dans [suspension-service](/repos/openmaraude/suspension-service) permet désormais de consulter et de gérer l'état de suspension des éléments, offrant ainsi une meilleure visibilité et un nouvel usage pour les utilisateurs. En parallèle, les travaux sur [suspension-service-api](/repos/openmaraude/suspension-service-api) préparent le terrain pour un déploiement web opérationnel de ces services.

## Autres changements notables
- **Infrastructure et déploiement** : Configuration de la couche réseau et du serveur web via la gestion des fichiers CNAME (DNS) et l'ajout de points d'entrée HTML pour les services de suspension ([suspension-service](/repos/openmaraude/suspension-service) et [suspension-service-api](/repos/openmaraude/suspension-service-api)).

## Dépôts les plus actifs
- [suspension-service](/repos/openmaraude/suspension-service) : Implémentation d'une page de gestion de l'état de suspension.
- [suspension-service-api](/repos/openmaraude/suspension-service-api) : Travaux de configuration technique pour le déploiement de l'API.
