## Changelog : multi-schema-postgres-etl (30 derniers jours, au 16 novembre 2026)

### Résumé
Le projet a bénéficié d'une mise à jour majeure de son socle technologique pour garantir sa pérennité et sa performance. Les versions de PostgreSQL et de Ruby ont été actualisées, et une nouvelle flexibilité a été ajoutée pour permettre de configurer précisément les versions des clients de base de données selon les besoins de chaque application.

### Évolutions techniques
- Mise à jour de l'environnement de base de données vers PostgreSQL 18 ([#27](https://github.com/betagouv/multi-schema-postgres-etl/pull/27)).
- Introduction de la possibilité de configurer la version du client PostgreSQL par application via une variable d'environnement ([#28](https://github.com/betagouv/multi-schema-postgres-etl/pull/28)).
- Mise à jour du runtime vers Ruby 3.4.12 ([#24](https://github.com/betagouv/multi-schema-postgres-etl/pull/24)).
- Mise à jour globale des dépendances (gems) du projet ([#25](https://github.com/betagouv/multi-schema-postgres-etl/pull/25)).
