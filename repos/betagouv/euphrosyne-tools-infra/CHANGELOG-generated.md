## Changelog : euphrosyne-tools-infra (30 derniers jours, au 01 mai 2026)

### Résumé
Ce mois-ci, l'infrastructure a été enrichie avec l'ajout d'une nouvelle politique de gestion des données pour "euphrosyne-data-cool" et d'un conteneur associé, désormais hébergé en privé.  Une nouvelle taille de machine virtuelle a également été ajoutée pour offrir plus de flexibilité. Enfin, la documentation a été améliorée.

### Évolutions fonctionnelles
- Ajout d'une nouvelle politique pour "euphrosyne-data-cool" [#1f1f750](https://github.com/betagouv/euphrosyne-tools-infra/commit/1f1f750).
- Ajout d'une nouvelle taille de machine virtuelle "Standard_E16s_v5" [#00fccdc](https://github.com/betagouv/euphrosyne-tools-infra/commit/00fccdc).
- Le conteneur "euphrosyne-data-cool" a été déplacé vers un registre privé [#f289c4c](https://github.com/betagouv/euphrosyne-tools-infra/commit/f289c4c).

### Évolutions techniques
- Mise à jour de Guacamole vers la version 1.6.0 [#2910281](https://github.com/betagouv/euphrosyne-tools-infra/commit/2910281).

### Autres changements
- Amélioration de la documentation README [#b737080](https://github.com/betagouv/euphrosyne-tools-infra/commit/b737080).
