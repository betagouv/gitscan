## Changelog : depenses-eclairees-waf (30 derniers jours, au 06 mai 2026)

### Résumé
Ce changelog détaille les premières configurations du Web Application Firewall (WAF) pour l'application de dépenses éclairées. Les travaux initiaux se sont concentrés sur la mise en place de la configuration Nginx et la définition de règles de sécurité personnalisées pour Metabase, l'outil de visualisation de données utilisé.

### Évolutions fonctionnelles
- Ajout de règles de sécurité personnalisées pour Metabase afin de renforcer la protection de l'application contre les attaques potentielles. [#3274435](https://github.com/betagouv/depenses-eclairees-waf/commit/3274435)
