## Changelog : beta.gouv.fr (30 derniers jours, au 3 juillet 2026)

### Résumé
Les récentes mises à jour de beta.gouv.fr se concentrent principalement sur l'amélioration de l'affichage des informations concernant les projets, notamment l'ajout de badges pour les lauréats EIG et les événements spéciaux (FAST, impact national). Des modifications de base de données régulières ont également été effectuées.

### Évolutions fonctionnelles
- Ajout d'un badge pour identifier les projets lauréats du programme EIG. [#21602](https://github.com/betagouv/beta.gouv.fr/issues/21602)
- Correction de l'affichage des badges pour les événements spéciaux (FAST, impact national). [#21590](https://github.com/betagouv/beta.gouv.fr/issues/21590)

### Évolutions techniques
- Suppression de fichiers inutiles du processus de construction pour optimiser le build. [#21599](https://github.com/betagouv/beta.gouv.fr/issues/21599)
- Correction d'une variable manquante (`LAST_COMMIT_DATE`).
- Mises à jour régulières de la base de données.
