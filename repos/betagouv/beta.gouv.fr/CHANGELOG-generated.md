## Changelog : beta.gouv.fr (30 derniers jours, au 24 juin 2026)

### Résumé
Ce mois-ci, les améliorations se concentrent sur la page "Startup" avec l'ajout d'indicateurs visuels pour les lauréats d'EIG et la correction d'erreurs d'affichage concernant les événements spéciaux et le comptage des startups. Des modifications de base de données régulières ont également été effectuées.

### Évolutions fonctionnelles
- Ajout d'un badge pour les lauréats de l'EIG (Entreprises Innovantes de Grande Croissance) sur la page "Startup" [#21602](https://github.com/betagouv/beta.gouv.fr/issues/21602).
- Correction de l'affichage du badge pour les événements spéciaux (FAST, impact national) sur la page "Startup" [#21590](https://github.com/betagouv/beta.gouv.fr/issues/21590).
- Correction du comptage des startups sur la page "Startup" [#21575](https://github.com/betagouv/beta.gouv.fr/issues/21575).

### Évolutions techniques
- Correction d'une variable manquante `LAST_COMMIT_DATE`.
