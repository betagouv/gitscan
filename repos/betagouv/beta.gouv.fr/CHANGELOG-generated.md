## Changelog : beta.gouv.fr (30 derniers jours, au 29 juin 2026)

### Résumé
Ce mois-ci, les améliorations se concentrent sur l'affichage des informations concernant les startups labellisées, notamment l'ajout de badges pour les lauréates EIG et la correction de l'affichage des badges pour les événements spéciaux (FAST, impact national). Des mises à jour régulières de la base de données ont également été effectuées.

### Évolutions fonctionnelles
- Ajout d'un badge pour les startups labellisées EIG, permettant de les identifier plus facilement. [#21602](https://github.com/betagouv/beta.gouv.fr/issues/21602)
- Correction de l'affichage des badges pour les événements spéciaux (FAST, impact national). [#21590](https://github.com/betagouv/beta.gouv.fr/issues/21590)

### Évolutions techniques
- Suppression de certains fichiers du processus de build pour optimiser la construction du site. [#21599](https://github.com/betagouv/beta.gouv.fr/issues/21599)
- Correction d'une variable manquante (`LAST_COMMIT_DATE`) pour assurer le bon fonctionnement du site.
- Mises à jour régulières de la base de données (plusieurs commits de `secretariat-bot`).
