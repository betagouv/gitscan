# Sekoia \<- Brevo Connector

A connector for `Sekoia` to pull information from `Brevo`.

## Contribute

```shell
# format the code
uv run black .

# run the tests
uv run pytest -v -s tests/

# typecheck the code
uv run mypy .
```
