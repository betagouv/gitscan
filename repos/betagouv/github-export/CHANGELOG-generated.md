## Changelog : github-export (30 derniers jours, au 21 juin 2026)

### Résumé
Les récentes modifications apportées au projet se concentrent sur l'amélioration de la gestion de l'état des migrations par les workflows GitHub Actions. Ces mises à jour visent à assurer un suivi plus précis et fiable des processus de migration des dépôts GitHub vers Codeberg.

### Évolutions techniques
- Amélioration de la gestion de l'état de la migration dans les workflows GitHub Actions après le traitement par lots et la découverte des dépôts. Ces mises à jour sont répétées à chaque exécution des workflows.
- Les actions `update migration state after batch processing` et `update migration state after discovery` ont été mises à jour à plusieurs reprises.

### Autres changements
- Aucune autre modification significative n'a été apportée au projet durant cette période.
