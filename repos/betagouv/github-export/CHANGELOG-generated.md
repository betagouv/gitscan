## Changelog : github-export (30 derniers jours, au 28 juin 2026)

### Résumé
Les récentes mises à jour se concentrent sur l'amélioration de la gestion de l'état des migrations par les workflows GitHub Actions. Ces changements visent à assurer un suivi plus précis et fiable des processus de migration de dépôts GitHub vers Codeberg.

### Évolutions techniques
- Amélioration de la gestion de l'état des migrations dans les workflows GitHub Actions après le traitement par lots et la découverte des dépôts. Ces mises à jour concernent les workflows `migrate-batch.yml` et `sync-orchestrator.yml`.
- Les actions de mise à jour de l'état de migration sont maintenant effectuées après chaque étape de traitement par lots et de découverte.

### Autres changements
- Aucune autre modification significative n'a été apportée au projet durant cette période. Les commits restants concernent des mises à jour automatiques de l'état de la migration.
