## Changelog : github-export (30 derniers jours, au 19 mai 2026)

### Résumé
Les récentes mises à jour de github-export se concentrent sur l'amélioration de la gestion de l'état de la migration. Ces changements visent à rendre le processus de migration plus fiable et à faciliter le suivi de la progression, notamment via les workflows GitHub Actions.

### Évolutions techniques
- Amélioration de la mise à jour de l'état de la migration après les phases de découverte et de traitement par lots dans les workflows GitHub Actions. Ces mises à jour sont effectuées par les workflows `migrate-batch.yml` et `sync-orchestrator.yml` [#34299c1](https://github.com/betagouv/github-export/commit/34299c1), [#0aea91a](https://github.com/betagouv/github-export/commit/0aea91a), [#b7d5c38](https://github.com/betagouv/github-export/commit/b7d5c38), [#b5d749d](https://github.com/betagouv/github-export/commit/b5d749d), [#efaa7ba](https://github.com/betagouv/github-export/commit/efaa7ba), [#4e2af11](https://github.com/betagouv/github-export/commit/4e2af11), [#5e01b22](https://github.com/betagouv/github-export/commit/5e01b22).
