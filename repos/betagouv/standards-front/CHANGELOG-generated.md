## Changelog : standards-front (30 derniers jours, au 21 mai 2026)

### Résumé
Cette mise à jour apporte des améliorations significatives à la gestion des standards, permettant désormais leur mise à jour via l'interface. Des ajustements ont également été effectués pour améliorer l'expérience utilisateur lors de l'affichage des versions des standards, et la configuration Docker a été mise à jour pour refléter les versions PostgreSQL utilisées sur Scalingo.

### Évolutions fonctionnelles
- Possibilité de mettre à jour les standards via l'application. [#181](https://github.com/betagouv/standards-front/pull/181)
- Amélioration de l'affichage des versions des standards : suppression de l'information "N/A" pour les versions non disponibles. [#181](https://github.com/betagouv/standards-front/pull/181)

### Évolutions techniques
- Mise à jour de la version Ruby à 4.0.5.
- Mise à jour de la configuration Docker pour utiliser les versions PostgreSQL de Scalingo.
- Mises à jour des gems (dépendances Ruby).

### Autres changements
- Mise à jour de la version Ruby à 4.0.3.
