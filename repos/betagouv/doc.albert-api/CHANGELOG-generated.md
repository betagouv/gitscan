## Changelog : doc.albert-api (30 derniers jours, au 25 mars 2026)

### Résumé
La documentation de l'API Albert a été initialisée et considérablement enrichie au cours des derniers jours. Les améliorations portent principalement sur la création de guides, la correction de liens brisés et l'adaptation de la documentation pour une meilleure compatibilité avec GitBook et l'API OpenAPI. De nouveaux workflows pour la création de clés API et de comptes ont également été ajoutés à la documentation.

### Évolutions fonctionnelles
- Ajout de guides pour les développeurs afin de faciliter l'intégration de l'API Albert.
- Ajout d'un workflow pour la création de clés API.
- Ajout d'un workflow pour la création de comptes.
- Intégration d'informations pertinentes provenant du site web Albert.

### Évolutions techniques
- Correction de problèmes de compatibilité avec GitBook, notamment la conversion de `const` en `enum` pour l'API OpenAPI [#aa2e40e](https://github.com/betagouv/doc.albert-api/commit/aa2e40e).
- Correction de problèmes de compatibilité de la référence API [#90d81f9](https://github.com/betagouv/doc.albert-api/commit/90d81f9).
- Réinitialisation du contenu de la documentation pour une resynchronisation avec GitBook [#578e206](https://github.com/betagouv/doc.albert-api/commit/578e206).

### Autres changements
- Création du fichier README.md initial [#ecf1803](https://github.com/betagouv/doc.albert-api/commit/ecf1803).
- Première version de la documentation complète [#14bb525](https://github.com/betagouv/doc.albert-api/commit/14bb525).
- Correction de liens brisés dans la documentation [#bad0104](https://github.com/betagouv/doc.albert-api/commit/bad0104) et [#d1da035](https://github.com/betagouv/doc.albert-api/commit/d1da035).
- Ajout d'un workflow de création de clés API visuel [#404cd94](https://github.com/betagouv/doc.albert-api/commit/404cd94).
