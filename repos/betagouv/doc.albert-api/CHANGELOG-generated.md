## Changelog : doc.albert-api (30 derniers jours, au 13 novembre 2026)

### Résumé
La documentation de l'API Albert a été enrichie d'informations importantes concernant les périodes de maintenance (Night Shift) et les spécifications techniques des modèles, notamment pour Gemma 4. Des corrections ont également été apportées aux guides d'utilisation pour faciliter l'intégration des développeurs.

### Évolutions fonctionnelles
- Ajout d'informations relatives au "Night Shift" sur la page des quotas pour une meilleure visibilité des périodes d'indisponibilité.
- Mise à jour des spécifications des modèles disponibles, incluant la précision de la longueur de contexte pour Gemma 4 ([#10](https://github.com/betagouv/doc.albert-api/pull/10)).
- Correction du guide de code concernant l'utilisation du proxy LLM ([#9](https://github.com/betagouv/doc.albert-api/pull/9)).

### Autres changements
- Mise à jour de l'URL de la clé API Albert dans la documentation.
- Amélioration de l'ergonomie de la documentation via l'ajout de composants extensibles (expanders).
- Corrections de diverses coquilles dans les textes.
