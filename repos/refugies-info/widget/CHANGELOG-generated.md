## Changelog : widget (30 derniers jours, au 22 octobre 2026)

### Résumé
Le projet entre dans sa phase initiale de développement. Les fondations techniques, incluant la structure du serveur backend et les processus de vérification automatique, ont été mises en place pour assurer une base de travail stable et sécurisée.

### Évolutions techniques
- Initialisation de l'architecture du backend avec le framework Fastify.
- Mise en place de l'intégration continue (CI) incluant des tests automatiques et un scan de sécurité des dépendances (OSV) via [#1](https://github.com/refugies-info/widget/pull/1).

### Autres changements
- Ajout de la documentation de base (README).
- Ajout de fichiers de configuration pour les outils d'assistance au développement (CLAUDE.md).
