## Changelog : fabnum-cicd (30 derniers jours, au 22 juin 2026)

### Résumé
Ce mois-ci, les améliorations se concentrent sur la simplification et l'unification des workflows d'attestation d'images Docker, ainsi que sur la mise à jour des versions des actions GitHub utilisées. Une nouvelle version majeure (0.7.0) a été publiée.

### Évolutions fonctionnelles
- **Attestation d'images :** L'action dédiée à l'attestation d'images a été remplacée par une nouvelle action unifiée, simplifiant ainsi le processus. [#889c417](https://github.com/dnum-mi/fabnum-cicd/commit/889c4179688e22e1d77dded27410a91720c4add7)

### Évolutions techniques
- **Mise à jour des actions :** Les versions des actions GitHub utilisées dans les workflows ont été mises à jour pour bénéficier des dernières corrections et améliorations. [#eb7136c](https://github.com/dnum-mi/fabnum-cicd/commit/eb7136cb583ad1eb4033112e167c41caafe10904)
- **Publication de la version 0.7.0 :** Nouvelle version majeure du dépôt. [#96fdb2e](https://github.com/dnum-mi/fabnum-cicd/commit/96fdb2e)
