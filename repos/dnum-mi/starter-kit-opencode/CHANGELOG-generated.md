## Changelog : starter-kit-opencode (30 derniers jours, au 24 juin 2026)

### Résumé
Ce kit de démarrage pour l'intégration d'agents d'IA (OpenCode, Claude, Codex) a été enrichi de documentation sur les compétences disponibles et d'une checklist pour faciliter l'implémentation de nouveaux plans.  Une amélioration de la configuration permet également une meilleure expérience de développement grâce à l'activation globale des serveurs LSP.

### Évolutions fonctionnelles
- Ajout d'une section dans la documentation `AGENTS.md` listant les compétences disponibles pour les agents. [#5](https://github.com/dnum-mi/starter-kit-opencode/issues/5)
- Mise à jour du fichier `SKILL.md` avec des informations complémentaires sur les compétences. [#2](https://github.com/dnum-mi/starter-kit-opencode/issues/2)
- Implémentation du chargement dynamique de `AGENTS.md` et des skills directement depuis GitHub Raw, facilitant ainsi les mises à jour de la documentation. [#1](https://github.com/dnum-mi/starter-kit-opencode/issues/1)

### Évolutions techniques
- Activation globale des serveurs LSP (Language Server Protocol) pour une meilleure expérience de développement et d'autocomplétion.

### Autres changements
- Ajout d'une checklist de vérification dans la documentation pour guider l'implémentation de nouveaux plans, incluant une référence au composant `DsfrInput`. [#4](https://github.com/dnum-mi/starter-kit-opencode/issues/4)
