## Changelog : plateforme-accueil (30 derniers jours, au 12 novembre 2026)

### Résumé
Les évolutions récentes se concentrent sur l'optimisation du référencement naturel (SEO) afin de garantir une gestion cohérente de l'indexation du contenu lorsqu'il est intégré dans d'autres sites via une iframe.

### Évolutions fonctionnelles
- Optimisation de l'indexation SEO : les pages sont désormais configurées pour ne pas être indexées de manière isolée, mais peuvent l'être lorsqu'elles sont intégrées dans un autre environnement.
