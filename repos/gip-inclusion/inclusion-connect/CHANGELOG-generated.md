## Changelog : inclusion-connect (30 derniers jours, au 18/08/2026)

### Résumé
Les évolutions récentes se sont concentrées sur l'amélioration de l'expérience de test via le mode de démonstration, offrant plus de flexibilité lors des phases de présentation ou de simulation.

### Évolutions fonctionnelles
- Personnalisation des profils en mode démo : possibilité de choisir le prénom et le nom de famille pour faciliter les tests utilisateurs.
