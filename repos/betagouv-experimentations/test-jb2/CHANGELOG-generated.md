## Changelog : test-jb2 (30 derniers jours, au 13 mai 2026)

### Résumé
Ce changelog marque le lancement initial du projet test-jb2. Il s'agit d'un prototype développé avec Claude Code et le Design System FR (DSFR) visant à faciliter la création rapide de services web pour l'administration. La première version met en place les fondations du projet, incluant la configuration initiale et la personnalisation du fichier README.

### Évolutions fonctionnelles
Aucune évolution fonctionnelle pour ce premier commit. Le projet est en phase de démarrage.

### Évolutions techniques
- Initialisation du projet avec les technologies suivantes : Next.js, React, TypeScript, PostgreSQL, Drizzle ORM, Zod et @codegouvfr/react-dsfr.
- Configuration initiale de l'environnement de déploiement avec Coolify via un workflow GitHub Actions. [#1](https://github.com/betagouv-experimentations/test-jb2/pulls/1)
- Mise en place d'un workflow CI/CD avec `bootstrap-coolify.yml`.

### Autres changements
- Personnalisation du fichier README avec une description du projet.
- Initialisation du dépôt avec un premier commit.
