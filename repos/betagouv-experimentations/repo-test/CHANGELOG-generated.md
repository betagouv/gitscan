## Changelog : repo-test (30 derniers jours, au 11 mai 2026)

### Résumé
Ce mois-ci, le projet a connu une avancée significative avec l'ajout d'une application de liste de tâches complète, incluant la création, la lecture, la mise à jour et la suppression d'éléments (CRUD).  L'application utilise PostgreSQL pour la persistance des données.  De plus, le projet a été initialisé avec une configuration Coolify et un fichier README personnalisé.

### Évolutions fonctionnelles
- Ajout d'une application de liste de tâches avec les fonctionnalités CRUD (Créer, Lire, Mettre à jour, Supprimer) et de filtrage. [#1](https://github.com/betagouv-experimentations/repo-test/pull/1)
- Persistance des données de la liste de tâches dans une base de données PostgreSQL. [#1](https://github.com/betagouv-experimentations/repo-test/pull/1)

### Évolutions techniques
- Initialisation de l'infrastructure Coolify pour le déploiement et l'hébergement. [#2](https://github.com/betagouv-experimentations/repo-test/pull/2)
- Personnalisation du fichier README pour une meilleure présentation du projet. [#2](https://github.com/betagouv-experimentations/repo-test/pull/2)
- Initialisation du dépôt avec un premier commit. [#3](https://github.com/betagouv-experimentations/repo-test/pull/3)
