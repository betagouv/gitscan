## Changelog : mediatech-to-albert-api (30 derniers jours, au 1er mai 2026)

### Résumé
Ce projet a connu une avancée significative avec la mise en place d'un pipeline automatisé pour importer les données du référentiel Mediatech de HuggingFace vers l'API Albert. Cette évolution permettra de maintenir l'API Albert à jour avec les dernières données légales françaises, améliorant ainsi la qualité des informations générées par la recherche (RAG). De plus, la base de données a été migrée vers une architecture serverless pour une meilleure scalabilité et gestion.

### Évolutions fonctionnelles
- Implémentation d'un pipeline d'ingestion des données Mediatech de HuggingFace vers l'API Albert. [#2](https://github.com/etalab-ia/mediatech-to-albert-api/issues/2)
- Mise en place d'un processus pour ingérer les "chunks" (fragments) de données Mediatech. [#2](https://github.com/etalab-ia/mediatech-to-albert-api/issues/2)

### Évolutions techniques
- Migration de la base de données vers une architecture serverless. [#3](https://github.com/etalab-ia/mediatech-to-albert-api/issues/3)
- Initialisation du dépôt et configuration de base.
