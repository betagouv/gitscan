## Changelog : floss-criteria (30 derniers jours, au 16 mai 2026)

### Résumé
Ce changelog présente les premières étapes de structuration des critères d'évaluation pour les logiciels libres. Les commits initiaux posent les bases de l'organisation des critères, incluant des réflexions sur la taille du code et la définition des décideurs dans le processus d'évaluation. Ces premiers pas visent à faciliter l'analyse et le choix de logiciels open source par les agents de l'administration.

### Évolutions fonctionnelles
- Ajout d'une première version des critères d'évaluation.
- Introduction d'une réflexion sur la prise en compte de la taille du code dans l'évaluation [#1](https://github.com/codegouvfr/floss-criteria/issues/1).
- Début de la formalisation des informations concernant les personnes responsables de la décision d'utilisation d'un logiciel.

### Évolutions techniques
- Initialisation du dépôt et de la structure de dossiers pour les critères.
- Mise en place d'un premier commit structurant le projet.

### Autres changements
- Nettoyage de code initial et suppression d'éléments obsolètes.
