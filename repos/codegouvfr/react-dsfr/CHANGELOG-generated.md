## Changelog : react-dsfr (30 derniers jours, au 24 avril 2026)

### Résumé
Cette mise à jour apporte une amélioration significative à la flexibilité du composant de texte, permettant désormais de spécifier la balise HTML utilisée pour le corps du texte. La documentation a également été mise à jour avec un exemple de site web utilisant la bibliothèque.

### Évolutions fonctionnelles
- Amélioration du composant `Text` : Possibilité de spécifier la balise HTML à utiliser pour le corps du texte via la prop `as` [#487](https://github.com/codegouvfr/react-dsfr/issues/487).

### Autres changements
- Mise à jour de la documentation : Ajout d'un exemple avec le site web de la Suite Territoriale de l'ANCT [#485](https://github.com/codegouvfr/react-dsfr/issues/485).
